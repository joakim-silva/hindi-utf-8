Consonants with Nukta

These are single-code-point encodings. A base consonant followed by the nukta (U+093C) can represent the same letter with a different byte sequence.

Common Combined Letters

These forms each contain two consonants joined by a halant: three code points and nine UTF-8 bytes. For example, क्ष = क + ् + ष.
